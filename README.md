# Market Brain

בוט איתותים לומד לכל מטבעות הקריפטו ב-Bybit (חוזי USDT), עם גרף חי.
הבוט נותן איתותי כניסה ויציאה בלבד. הוא לא מבצע עסקאות ולא מהווה ייעוץ השקעות.

## הפעלה

```bash
npm install
npm start
```

ואז לפתוח http://localhost:4600 וללחוץ על "הפעל צליל והתראות".

## איך זה עובד

1. **נתונים** – כל חוזי ה-USDT הקריפטוגרפיים ב-Bybit (כ-500), נרות של שעה כברירת מחדל.
2. **אינדיקטורים** – UT Bot, VWAP יומי, SSL Channel, RSI, EMA200, נפח חריג, ומצב ה-BTC (`src/indicators.js`).
3. **המוח** – רגרסיה לוגיסטית שלומדת אונליין (`src/model.js`). בכל נר שנסגר הבוט בודק מה קרה
   ל"עסקה" שהייתה נפתחת 24 נרות קודם (סטופ 1.5 ATR, יעד 2.25 ATR, אחרי עמלות) ומעדכן את המשקלים.
   יש מודל כללי לכל השוק ותיקון קטן לכל מטבע.
4. **לוח תוצאות כן** – כל תחזית נשמרת ברגע שהנר נסגר ונבדקת רק אחרי שהתוצאה ידועה, כך שאין הצצה לעתיד.
5. **איתות כניסה** – רק כשיש טריגר טרי (היפוך UT Bot / חציית VWAP / היפוך SSL), הביטחון של המודל מעל הסף,
   ורמת הביטחון הזאת הוכיחה רווח בפועל ב-30 הימים האחרונים.
6. **איתות יציאה** – נגיעה בסטופ או ביעד, היפוך UT Bot נגד העסקה, ירידה בביטחון המודל, או 24 נרות בלי הכרעה.

## הגדרות (משתני סביבה)

| משתנה | ברירת מחדל | משמעות |
|---|---|---|
| `TF` | `60` | גודל הנר שעליו הבוט עובד: 5 / 15 / 60 / 240 |
| `MIN_PROB` | `0.5` | ביטחון מינימלי לאיתות |
| `MIN_EV` | `0.03` | רווח מוכח מינימלי (ב-R) לרמת הביטחון |
| `MIN_TURNOVER` | `2000000` | נפח 24 שעות מינימלי ($) למטבע שמקבל איתות |
| `MAX_OPEN` | `8` | מספר מקסימלי של איתותים פתוחים במקביל |

## העלאה ל-Render

הקובץ `render.yaml` מוכן. חשוב: אזור מחוץ לארה"ב (Bybit חוסם כתובות אמריקאיות), ותוכנית בתשלום
כדי שהשרת לא יירדם. מצב הלמידה נשמר ב-`data/state.json`; בלי דיסק קבוע הבוט לומד מחדש מההיסטוריה בכל הפעלה (כדקה).
